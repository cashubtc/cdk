# CDK Code Review

Before reviewing, read and follow the shared
[CDK Code Review Guidelines](../../../docs/code-review.md). Resolve these links
relative to this skill directory, regardless of the current working directory.

Establish the requested revision or diff and inspect the affected code and
callers. Apply the relevant checks from the guide and report findings with
evidence, precise locations, and validation performed. Keep review policy in the
shared guide rather than duplicating it here.

When JSON output is requested and the caller does not supply a schema, also read
and use the [automated review JSON format](../../../docs/code-review-json.md).
