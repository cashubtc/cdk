# BLS federation field notes

Interactive vertical slide-show built from `../FEDERATION_NOTES.md`.

```bash
npm install
npm run dev
```

Use the right rail or `↑` / `↓` to move between pages. Several protocol figures are interactive: keyset versions, proof lifecycle, threshold interpolation, mix-and-match, transport topology, DKG, treasury flows, and recovery states.

To open `index.html` directly as a local file, run `npm run build` once first; the file-safe bootstrap will load the production bundle from `dist/`.
